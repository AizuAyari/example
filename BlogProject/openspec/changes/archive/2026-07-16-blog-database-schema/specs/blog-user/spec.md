## ADDED Requirements

### Requirement: 組み込みUserモデルによるユーザー管理
システムは Django 組み込みの `django.contrib.auth.models.User` モデルをそのままユーザーの識別・認証情報の格納先として使用しなければならない（MUST）。カスタムユーザーモデルへの置き換えは行わない。

#### Scenario: ユーザー名の一意性
- **WHEN** 既に登録済みのユーザー名で新規ユーザーを作成しようとする
- **THEN** Django 組み込みの一意制約によりデータベースレベルでエラーとなり、重複したユーザーは作成されない

#### Scenario: パスワードのハッシュ化保存
- **WHEN** ユーザーがパスワードを設定してアカウントを作成する
- **THEN** パスワードは平文ではなく Django 標準のハッシュアルゴリズムでハッシュ化された状態でデータベースに保存される

### Requirement: 記事とユーザーの関連付け
`Article` モデルはユーザーを著者として参照できなければならない（MUST）。著者ユーザーが削除された場合、そのユーザーが投稿した記事も連鎖的に削除されなければならない（MUST）。

#### Scenario: ユーザー削除時の記事連鎖削除
- **WHEN** ある著者ユーザーがデータベースから削除される
- **THEN** そのユーザーが著者である全ての `Article` レコードも削除される
